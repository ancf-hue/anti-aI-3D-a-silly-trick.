## 🎯 О проекте

**Анти-ИИ: 3D Дурак Подкидной** — это браузерная карточная игра, где вы играете против компьютерного соперника в классический подкидной дурак на красивой 3D-сцене.

Название «**Анти-ИИ**» отражает главную цель — **победить ИИ** и не остаться в дураках! 💪

Полностью реализованы правила подкидного дурака с корректной логикой, тремя уровнями сложности, русским и английским интерфейсом, а также защитой от зависаний — игра никогда не застрянет на мёртвой точке.

## ✨ Особенности

### 🎮 Игровой процесс
- ✅ **Полные правила подкидного дурака** — корректная логика подкидывания, добора карт, взятия
- ✅ **Лимит 6 карт в одной атаке** — классическое ограничение
- ✅ **Защитник не добирает карты** при взятии со стола (правильная логика)
- ✅ **Анти-зависание** — автоматическое завершение хода при 0 карт у атакующего
- ✅ **Сортировка карт** — по масти, старшинству, козыри справа

### 🤖 ИИ-соперник
- 🟢 **Easy** — случайные ходы, подходит новичкам
- 🟡 **Normal** — умеренная сложность, сбалансированная игра
- 🔴 **Hard** — жёсткий ИИ, подкидывает минимальные карты, экономит козыри

### 🎨 Визуал и UX
- 🎬 **Полноценная 3D-сцена** на Three.js с тенями и освещением
- 📱 **Адаптивный дизайн** — играйте на телефоне, планшете или ПК
- 🎴 **Анимации карт** — плавные твины при розыгрыше
- 💡 **Подсветка доступных ходов** — видно, какие карты можно сыграть
- 📊 **Счёт побед/поражений/ничьих** — сохраняется в localStorage

### 🔊 Звук
- 🎵 Звуки действий (карты, взятие, бито, победа)
- 🗣️ Голосовые уведомления через Web Speech API (RU/EN)
- 🔇 Кнопка включения/выключения звука
- 📴 Автопауза при сворачивании вкладки

### 🌍 Локализация
- 🇷🇺 Русский язык
- 🇬🇧 English
- Переключение языка одним кликом
